# 우리 가계부

부부가 각자 폰(아이폰/갤럭시)에서 입력하면 서로 바로 보이는 공유 가계부입니다.
앱스토어 없이 **웹앱(홈 화면에 추가)** 으로 쓰고, 비용은 0원입니다.

## 준비 (한 번만, 약 15분)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 접속 → 구글 로그인 → **프로젝트 추가** (이름 자유, 애널리틱스는 꺼도 됨)
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 이메일/비밀번호 → 사용 설정**
3. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**로 시작
4. Firestore의 **규칙** 탭에 이 폴더의 `firestore.rules` 내용을 통째로 붙여넣고 **게시**
5. 톱니바퀴(프로젝트 설정) → **내 앱 → 웹(</>)** 추가 → 나오는 `apiKey`, `authDomain`, `projectId`, `appId` 값을 `firebase-config.js`에 붙여넣기

### 2. 인터넷에 올리기 (무료)
가장 쉬운 방법은 **Firebase Hosting** 또는 **GitHub Pages**입니다.
- GitHub Pages: 저장소 Settings → Pages → 브랜치 선택 → 주소가 생김 (`https://아이디.github.io/budget/`)
- 생긴 주소를 Firebase 콘솔 → Authentication → 설정 → **승인된 도메인**에 추가

### 3. 폰에 설치
- **아이폰**: 사파리로 주소 접속 → 공유 버튼 → **홈 화면에 추가**
- **갤럭시**: 크롬으로 주소 접속 → 메뉴(⋮) → **홈 화면에 추가 / 앱 설치**

### 4. 부부 연결
1. 한 명이 가입 → **새로 만들기** → 화면 아래에 나오는 **초대 코드** 확인
2. 다른 한 명이 가입 → 코드 입력 → **코드로 참여**

## 기능
- **가계부**: 일일 목록 / 달력 보기, 수입·지출·합계, 작성자·결제수단 필터
- **입력**: 날짜 → 금액 → 분류 → 결제수단 → 내용 한 줄씩. 칸을 누르면 키패드 자리에 선택 창(달력 / 대분류·소분류 / 결제수단). "계속 입력", 눌러서 수정·삭제
- **분류**: 대분류 11개 + 소분류, 소분류 직접 추가 가능
- **결제수단**: 사람마다 따로 등록(내 것 / 공용 / 상대), 입력할 때는 내 것·공용 위주로
- **통계**: 분류별 / 결제수단별 / 작성자별 도넛 차트, 지난달 대비. 대분류를 누르면 소분류 상세
- **예산**: 한 달 총액 + 분류별 예산, 남은 날 기준 하루 사용 가능액, 초과 경고
- **더보기**: 별명 변경, 결제수단 관리, 초대 코드 복사, 로그아웃
- 한 명이 입력하면 상대 폰에 바로 표시 (실시간), 인터넷이 끊겨도 입력 가능

## 업데이트할 때 주의
보안 규칙(`firestore.rules`)이 바뀌면 Firebase 콘솔 → Firestore → **규칙** 탭에 새 내용을 붙여넣고 **게시**해야 합니다.

## 파일 설명
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 |
| `app.js` | 동작 (로그인, 저장, 실시간 목록) |
| `firebase-config.js` | 내 Firebase 연결 정보 (직접 채워야 함) |
| `firestore.rules` | 두 사람만 볼 수 있게 하는 보안 규칙 |
| `manifest.json`, `sw.js`, `icons/` | 홈 화면 앱 설정 |

## 로컬에서 미리 보기
`python3 -m http.server 8000` 실행 후 http://localhost:8000
